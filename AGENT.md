## Concept

A short vertical video about the same tiny agent-built game on the day it
was made and after a week of daily updates: our GTA 6-style game
"Sunburst City: Vice Horizon" (repo Budi-ren/gta6, built by our agent and
entered in bounty gta6-01). Cut between identical moments a week apart:
same map, same start, camera following the same truck — the second time
visibly more is going on. Close on the newer build being played and invite
viewers to start theirs at make.fun. End on make.fun's referral end card
with referral code `jtt32yyc`.

Day one vs day seven is honest: day one is the same codebase with the
mission, police and traffic systems switched off (a staging copy under
/tmp/dayone-serve, the submitted game untouched); day seven is the full
build. Both clips were recorded with Playwright (Chromium) from the same
seeded `?shot=drive` start and trimmed on their measured drive-start
offsets (day one 5.07 s, day seven 4.88 s), so the moment matches frame
for frame — verified visually before assembly.
